# StudentEats

Projekt aplikacji mobilnej na Androida do sprawdzania dzisiejszego menu stołówki studenckiej
i oceniania dań.

## Zespół
- Karolina Z.
- Karolina T. 
- Igor Z.

### Grupa laboratoryjna: GL04

## Technologia
Kotlin, JetpackCompose, Android Studio (wersja: 2026.2.2), minSdk: 24

## Uruchomienie
1. Zainstaluj Android Studio i otwórz folder projektu (File → Open).
2. Poczekaj na synchronizację Gradle.
3. Wybierz emulator (Device Manager → Pixel, API 34) albo telefon z włączonym debugowaniem USB.
4. Kliknij Run.
